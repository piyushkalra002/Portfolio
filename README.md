## 📤 Push to GitHub & Publish Live (GitHub Pages)

To publish this portfolio live to your GitHub account (`github.com/piyushkalra002`):

### Option 1: Live Domain at `piyushkalra002.github.io`
1. Go to [github.com/new](https://github.com/new) and create a repository named **`piyushkalra002.github.io`**.
2. Run the following commands in terminal:

```bash
git remote add origin https://github.com/piyushkalra002/piyushkalra002.github.io.git
git branch -M main
git push -u origin main
```
3. Your portfolio will automatically be live at: **`https://piyushkalra002.github.io`**!

### Option 2: Project Repository at `github.com/piyushkalra002/portfolio`
1. Go to [github.com/new](https://github.com/new) and create a repository named **`portfolio`**.
2. Run the following commands:

```bash

git branch -M main
git push -u origin main
```
3. In your GitHub repository settings, go to **Pages** -> **Source** -> Select **`main` branch** -> Save.
